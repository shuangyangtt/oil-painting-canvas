支持自建私有服务器和服务器测速，平板下载达到 **58 MB/s**。

在家里电脑上用 podman 跑 `invidious` + `invidious-companion`（可生成 PO Token，儿童内容能正常获取）+ `postgres`，开机自启、每天自动更新，只对热点开放。平板默认用它，公共服务器作备用。家长设置可给每台服务器测速，并一键选最快。

接入时修了四个问题：

- **连不上**：电脑防火墙的热点区域只放行 DHCP/DNS/SSH，放行服务端口后解决
- **被误切换**：切换瞬间旧服务器的报错被算到新服务器头上；现在按报错里的主机判断
- **只有 8 MB/s**：v1.9 给公共服务器的「一次一个」限速被套在了自建服务器上；私有服务器改为可同时 8 个
- **字幕太少**：只找频道语言的字幕，带中文字幕的英文歌也被判为没有；改为「频道语言 → 中文 → 英文」，覆盖率 15% → 33%

已知：少数歌只能拿到 480p 的 H.264；私有服务器需要电脑开着，但出门只放已存的歌，不受影响。

**关键代码**

服务器配置要点（podman pod，节选；`<热点IP>` 换成自己的）：

```yaml
- {containerPort: 3000, hostPort: 3000, hostIP: <热点IP>}     # 只对热点开放
invidious_companion:
  - private_url: "http://localhost:8282/companion"
    public_url: "http://<热点IP>:8282/companion"              # 必须是平板能访问的地址
```

```
sudo firewall-cmd --permanent --zone=nm-shared --add-port=3000/tcp --add-port=8282/tcp
```

私有服务器放开到同时 8 个请求，公共服务器仍然一次一个（`Offline.kt`）：

```kotlin
private suspend fun <T> gated(block: suspend () -> T): T {
    if (state.store.instance == LOCAL_INSTANCE) return localGate.withPermit { block() }   // Semaphore(8)
    return manifestGate.withPermit { /* 一次一个，间隔 700 ms */ }
}
```

报错里写的是别的服务器，就不怪当前服务器（`AppState.failover`）：

```kotlin
if (reason != null && !reason.contains(hostOf(current)) &&
    store.instances.any { it != current && reason.contains(hostOf(it).substringBefore(":")) }
) return true
```

字幕按「频道语言 → 中文 → 英文」打分，同语言里人工优先（`Data.kt`）：

```kotlin
val groups = when (lang) {
    "zh" -> listOf(zh, listOf("en"))
    "de" -> listOf(listOf("de"), zh, listOf("en"))
    else -> listOf(listOf("en"), zh)
}
return (groups.size - group) * 1000 + (if (auto) 0 else 100) + (wanted.size - i)
```
