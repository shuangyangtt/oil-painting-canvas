修复平板版下载跑一阵后变成一次只下一首（4 MB/s），现在恢复到 45～49 MB/s。

- 旧版本留下的歌单只有 1 页，但 12 小时内被当作新鲜，后面 4 页一直没取；现在只有 1 页的歌单直接重新取
- 下载任务找不到歌就休息 10 分钟，32 个任务陆续睡着；现在只要还有任务在下或歌单在加载，只等 30 秒

**关键代码**

```kotlin
// Offline.kt：暂时没歌可下 ≠ 全部下完
if (target == null) {
    val stillGoing = synchronized(lock) { busy.isNotEmpty() } || state.rows.values.any { it.loading }
    if (stillGoing) return 30_000                 // 30 秒后再找
    status = "推荐的歌都已存好"
    return 10 * 60_000L
}

// AppState.kt：平板版只有一页（≤ 60 首）的歌单视为过期
val fresh = cached != null && System.currentTimeMillis() - cached.first < ROW_MAX_AGE_MS &&
    (!BuildConfig.PAD || cached.second.size > 60)
```
