新增平板版：在家用 WiFi 自动把儿歌下载到平板上，出门不用网也能看。

- **两个版本共用一套代码**：用 Gradle 的 product flavor 分成 `tv` 和 `pad`，代码里用 `BuildConfig.PAD` 区分；平板版应用 ID 是 `app.youtubu.tv.pad`，可与投影仪版同时安装
- **自动下载**：后台下载器是 Kotlin 协程循环（`Precacher`），视频存进 AndroidX Media3 的 `SimpleCache`（按最久未用淘汰）；每首只存 720p H.264 + AAC 两条轨，并生成一份本地 DASH 清单供离线播放
- **关掉界面也继续下**：安卓前台服务（`DownloadService`，类型 dataSync）托住进程，加 `PowerManager` 唤醒锁和 `WifiManager` WiFi 锁
- **孩子界面**：Jetpack Compose 写的大封面列表，封面用 Coil 加载并提前缓存；播放用 Media3 ExoPlayer
- **家长入口**：按住小锁 2 秒，用 Compose 的长按手势检测实现
- **夜间下载**：华为熄屏约 2 分钟会冻结应用（系统日志可见 `NetworkRestrict`），应用无法绕过。改为插电且在下载时用 `FLAG_KEEP_SCREEN_ON` 保持亮屏，1 分钟无操作把窗口亮度设为 1% 并显示黑屏；充电状态来自系统电池广播 `ACTION_BATTERY_CHANGED`。实测 2 分半钟持续下载 27 首
