**关键代码**

平板版沿着 `continuation` 翻 5 页歌单，每页间隔 1.5 秒（`Data.kt`）：

```kotlin
val pages = if (BuildConfig.PAD) 5 else 1
for (page in 1..pages) {
    val path = "/api/v1/channels/$channelId/videos?sort_by=popular" +
        (token?.let { "&continuation=" + URLEncoder.encode(it, "UTF-8") } ?: "")
    val json = try { JSONObject(get(path)) } catch (e: Exception) { if (page == 1) throw e else break }
    // … 收集本页视频 …
    token = json.optString("continuation").ifEmpty { null } ?: break
    delay(1_500)
}
```

播放时把字幕合进视频，开关只切换文本轨，不用重新缓冲（`PadPlayer.kt`）：

```kotlin
val source = if (sub == null) dash else MergingMediaSource(
    dash,
    SingleSampleMediaSource.Factory(DefaultDataSource.Factory(context)).createMediaSource(
        MediaItem.SubtitleConfiguration.Builder(Uri.fromFile(sub))
            .setMimeType(MimeTypes.TEXT_VTT).setSelectionFlags(C.SELECTION_FLAG_DEFAULT).build(),
        C.TIME_UNSET,
    ),
)
player.trackSelectionParameters = player.trackSelectionParameters.buildUpon()
    .setTrackTypeDisabled(C.TRACK_TYPE_TEXT, !subtitles).build()
```
