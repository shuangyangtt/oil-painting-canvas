新增中文分类、字幕，平板缓存提高到 128 GB。

- **语言分类**：频道数据加 `lang` 字段；顶部「中文 / English / Deutsch」按钮用 Compose 实现，选择存在 SharedPreferences；新频道按名称用正则判断语言（汉字 → 中文，德语字母和常见词 → 德文）
- **8 个官方中文频道**：宝宝巴士、碰碰狐、Bebefinn、贝乐虎、CoComelon 中文版、儿歌多多、小宝贝布姆、小伊普童谣。按名字猜 YouTube 用户名混进了仿冒账号，改为解析 YouTube 频道搜索页（`ytInitialData`），按订阅数逐个核对；欧盟地区需要带 cookie 同意参数才能拿到结果
- **字幕**：调用 Invidious 的 `/api/v1/captions` 接口取 WebVTT 文件，存在歌旁边；播放时用 Media3 的 `MergingMediaSource` 把字幕和视频合并，「字」按钮通过轨道选择参数开关字幕轨，不用重新缓冲
- **128 GB**：每个频道沿 Invidious 的 `continuation` 翻 5 页（约 300 首），否则存不满；为了不给服务器压力，歌单一次只加载一个频道，每页间隔 1.5 秒

本版在封禁期间开发，界面在断网下测试，字幕和中文歌单在 v2.2 实测。
