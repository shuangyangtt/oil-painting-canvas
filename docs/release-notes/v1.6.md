v1.6 为平板版加入了网络类型感知，并为缓存引入了「满即止」的策略。这两项改动都源于同一个使用场景：平板是随身设备，离家后可能通过手机热点上网，而 v1.5 的下载器对网络类型一视同仁，只要有连接就会持续拉取数据——在热点环境下，这意味着可能在不知不觉中消耗十几 GB 的移动流量。

我们没有让家长手动维护「哪些网络可以下载」的白名单，而是依赖安卓系统自身的计费网络语义。系统会把移动数据和绝大多数手机热点标记为「按流量计费」（metered），把普通家用 WiFi 标记为不计费。下载器在每一轮调度前调用 `ConnectivityManager.isActiveNetworkMetered()` 进行判断：若当前为计费网络，则既不下载歌曲，也不刷新歌单，并在家长设置中明确提示「只用 WiFi 下载：现在连的是手机热点或流量，不下载」，随后以一分钟为周期重新检测，一旦回到家中 WiFi 即自动恢复。与此同时，缓存达到 16 GB 上限后下载会停止，离家后设备只播放已有内容，存储占用保持可预期。

这次改动暴露了 v1.5 夜间下载模式的一个设计缺陷。夜间模式原先的触发条件是「仍有未下载的内容」，这在加入网络判断之前是合理的；但现在，在外充电而又没有 WiFi 时，下载实际上处于暂停状态，屏幕却会因为「还有歌没下完」而一直保持点亮，既浪费电量也影响休息。我们把条件收紧为「下载器当前确实处于写入状态」——实现上以调度器状态是否为「正在存……」为准——因此在无网络、计费网络、缓存已满或用户关闭自动下载时，屏幕都会按系统设置正常熄灭。

上线后我们在设备上确认，家中 WiFi 被系统正确识别为不计费网络（`NOT_METERED`），下载照常进行。需要指出的是，热点的识别依赖手机端是否在 DHCP 或热点信标中声明了计费属性。主流的安卓手机和 iPhone 热点都会声明，但少数设备可能不会，此时平板仍会把它当作普通 WiFi 下载。投影仪版功能不变。
