平板版只用家里的 WiFi 下载，存满 16 GB 自动停止。

- 连手机热点或移动数据（系统标记为计费网络）时不下载，避免偷跑流量
- 顺带修正 1.5 的问题：在外充电没 WiFi 时屏幕不再一直亮着，只有真正在下载时才常亮
- 热点能否被识别，取决于手机是否把它标成计费网络；个别设备可能识别不出

**关键代码**

```kotlin
// Data.kt：家里的 WiFi = 有网络且不计费
fun unmetered(context: Context) = cm.activeNetwork != null && !cm.isActiveNetworkMetered

// Offline.kt：下载器每轮开始前检查
if (BuildConfig.PAD && !Net.unmetered(context)) {
    status = "只用 WiFi 下载：现在连的是手机热点或流量，不下载"
    return 60_000
}

// PadNight.kt：只有真正在存歌时才常亮
fun downloading(state: AppState) =
    state.store.autoPrecache && (state.precacher.status.startsWith("正在存") || state.precacher.status == "等待开始")
```
