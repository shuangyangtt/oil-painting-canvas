平板版下载提速：实测从 2 KB/s（基本卡死）提升到约 4.5 MB/s。

原因是我当初写得太简单：一次只下一首、一个文件一条连接（会被 YouTube 限速）、卡住要等 40 秒、一首出错全部停 30 秒。

- 同时下 4 首，画面和声音并行
- 每个文件按 4 MB 分段下载，失败只重试该段，支持断点续传
- 连接卡住 15 秒即重连；一首出错不影响其他
- 家长设置显示实时速度和每首进度
- 预留 1 GB 余量，避免并行下载时挤掉已存的歌

**关键代码**

按 4 MB 分段，已存的段跳过，单段失败最多重试 4 次（`Offline.kt` 的 `cacheStream`）：

```kotlin
while (pos < size) {
    val len = minOf(CHUNK, size - pos)                       // CHUNK = 4 MB
    if (cache.getCachedBytes(key, pos, len) < len) {         // 已存好的段直接跳过
        val spec = DataSpec.Builder().setUri(uri).setPosition(pos).setLength(len).build()
        // 失败重试：attempt 1..4，每次多等 1 秒
        runWriter(spec, onBytes)
    }
    pos += len
}
if (cache.getCachedBytes(key, 0, Long.MAX_VALUE) < size) throw IOException("没有存完整")
```

暂停和超时都会抛 `InterruptedIOException`，用标记区分开（`runWriter`）：

```kotlin
} catch (e: InterruptedIOException) {
    if (pausing) throw Paused()                // 开始播放视频 → 暂停，稍后继续
    throw IOException("连接卡住，重新连接")      // 读超时 → 进入重试
}
```
