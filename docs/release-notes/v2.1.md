支持多个视频服务器，出问题自动切换。

- 当前服务器出错时切到下一个；出过问题的 10 分钟内不再切回
- 换服务器不影响已存内容，下到一半的文件可继续
- 家长设置可添加服务器，加入前会先实测能否使用

找备用服务器时：约 20 个公共 Invidious 和 Piped 实例都不可用；yt-dlp 直连 YouTube 对儿童内容提示不可播放（缺少 PO Token）。所以本版完成时实际只有一个服务器，问题在 v2.2 解决。

**关键代码**

选下一个 10 分钟内没出过问题的服务器；刚切换的 30 秒内不再切（`AppState.kt`）：

```kotlin
fun failover(reason: String?): Boolean {
    val now = System.currentTimeMillis()
    if (now - lastSwitch < 30_000) return true            // 旧请求的报错，忽略
    failedAt[store.instance] = now
    val next = store.instances.firstOrNull { it != store.instance && now - (failedAt[it] ?: 0) > 10 * 60_000 }
        ?: return false                                    // 没有可换的 → 全部暂停等待
    lastSwitch = now
    store.instance = next
    return true
}
```
