限制向 Invidious 主服务器发请求的频率，服务器忙时全部暂停。

v1.8 的 32 路并发在几分钟内向主服务器要了几百次播放清单，我们的 IP 被封了（服务器本身正常、视频中转仍可访问）。公共服务器由志愿者维护，这是我考虑不周。

- 清单请求排队：一次一个，间隔 0.7 秒；视频数据仍并行下载
- 遇到 429、5xx 或连不上时，全部暂停 1 分钟，再出问题就翻倍，最长 30 分钟
- 429 不再计为这首歌失败，避免好歌被跳过

**关键代码**

发往主服务器的请求排队：一次一个，间隔 0.7 秒（`Offline.kt`）：

```kotlin
private val manifestGate = Semaphore(1)

private suspend fun <T> gated(block: suspend () -> T): T = manifestGate.withPermit {
    val wait = lastManifest + MANIFEST_GAP_MS - System.currentTimeMillis()   // 700 ms
    if (wait > 0) delay(wait)
    try { block() } finally { lastManifest = System.currentTimeMillis() }
}
```

服务器忙时全部暂停，时长翻倍，最长 30 分钟：

```kotlin
if (System.currentTimeMillis() >= holdUntil) {
    holdUntil = System.currentTimeMillis() + holdStep
    holdStep = minOf(holdStep * 2, 30 * 60_000L)     // 1 → 2 → 4 … → 30 分钟；成功后复位为 1 分钟
}
```
